Browser extension

GPTTrace for Chrome: check any image or text with a right-click

Spot a suspicious photo or a paragraph that reads like a chatbot? Right-click it. GPTTrace checks it on your own computer and shows the verdict with the evidence behind it, without sending anything anywhere.

Install

Add GPTTrace to Chrome

The extension works in Google Chrome and in other Chromium browsers that install from the Chrome Web Store, including Microsoft Edge and Brave. After installing, there is nothing to set up and no account to create. Two new items appear when you right-click: Check image with GPTTrace on any picture, and Check text with GPTTrace on any text you have selected.

What happens when you right-click

A small window opens next to the page and runs the check. For an image, it first reads whatever the file says about itself: signed Content Credentials (C2PA), the IPTC tag that generators such as Adobe Firefly and Google write to mark AI output, and the generation settings that tools like Stable Diffusion leave in PNG files. When those are present they settle the question. When they have been stripped, which happens to almost every image re-uploaded to social media, two neural classifiers and a set of pixel-level forensic checks estimate how likely the image is to be AI-generated.

For text, the standard check is instant. It measures the habits language models over-use: certain stock phrases, very even sentence rhythm, predictable vocabulary. If you turn on the deep scan, GPTTrace also runs its own neural text model, trained on the RAID and MAGE research benchmarks, which catches current chatbots far more often than pattern rules can.

Either way, the window shows a verdict, an estimated probability, a confidence level and the individual signals that pushed the score toward AI or toward human. A link opens the full report on gpttrace.com when you want the larger views, such as the error-level map of an image.

Private by design

Most AI checkers work by uploading what you give them to a server. That is a problem when the thing you want to check is a private message, a student’s essay, a document under embargo or a photo of a person. The GPTTrace extension never uploads it. The check runs in the extension itself, on your processor, using the same WebAssembly engine that powers the website. There is no account, no tracking and no analytics code in the extension, and the permissions it asks for at install are only those needed to add the right-click items and read the one selection or image you chose.

The models are downloaded the first time they are needed and cached by the browser, so later checks are fast and work even with a weak connection. Our privacy page explains the same guarantees for the website.

How accurate is it?

The extension gives exactly the same answer as gpttrace.com for the same input, because it runs the same code and the same models. On our labelled set of 635 images, the image detector reaches a cross-validated AUC of 0.98 and catches 84% of AI images while wrongly flagging about 5% of real photos. On 2,467 text passages, the standard text check scores an AUC of 0.80 and the deep scan 0.96, with both tuned so that around 5% or fewer human texts cross the “Likely AI” line. The methodology page describes the test sets, and the benchmark page lists our results on public research benchmarks, weak spots included.

No detector is perfect. Text under about 150 words is unreliable for every tool, some new image generators slip past classifiers, and a re-uploaded screenshot has lost the metadata that would otherwise prove its origin. Treat a result as one piece of evidence and never as the only reason to accuse someone of using AI.

Good uses

  • Fact-checking a viral photo before you share it, straight from the social feed or news site where you saw it.
  • Reading reviews, posts and comments that feel machine-written, by selecting a paragraph and checking it in place.
  • Teaching and editing, where a quick second opinion helps you decide whether a conversation is needed, without sending someone’s work to a third party.
  • Checking a profile picture that looks a little too perfect, on dating sites, marketplaces or LinkedIn.

Frequently asked questions

Is the GPTTrace extension free?
Yes. There is no account, no limit and no paid feature inside the extension. It runs the same free, on-device detectors as gpttrace.com.
Does the extension upload what I check?
No. The image or text is analysed inside the extension on your computer. It has no analytics and no server it reports to. The only downloads are the detection models, fetched once from gpttrace.com and then cached.
Why does it sometimes ask to read images from a website?
Most sites let extensions read their images. A few don’t, and then GPTTrace shows an “Allow” button for that one site. The permission only lets the extension download the image you right-clicked so it can check it locally; you can remove it at any time in Chrome’s extension settings.
Is there a version for Firefox, Edge or Safari?
Edge can install it from the Chrome Web Store today. Firefox and Safari versions are built from the same code and are being prepared for their stores; this page will link them when they are live.
Why is the deep text scan a separate step?
It uses a 144 MB neural model. The extension downloads it only the first time you ask for a deep scan, so people who only check images never pay that download.
